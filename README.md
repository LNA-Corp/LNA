# LNA Corp

Wix corporate site migrated to Next.js,
styled in the same grain as the LSR landing page.

## Pages

- `/` Home
- `/about` About + Our Labs
- `/mission` Mission + Philosophy
- `/systems` Systems + Engines
- `/contact` Contact

## Develop

```bash
cd C:\Users\user\LNA\lna-corp
npm install
npm run dev
```
